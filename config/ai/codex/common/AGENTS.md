# Global working agreements

- Keep durable project knowledge in that project's checked-in `AGENTS.md` or
  documentation so it follows the repository to every machine.
- Never commit API keys, passwords, access tokens, private `.env` files, login
  sessions, or generated chat databases to a project or dotfiles repository.
- Prefer cross-platform commands and paths when a project supports both Windows
  and Linux; document unavoidable operating-system differences.
